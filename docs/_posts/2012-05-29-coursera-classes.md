I’ve been increasingly impressed by the quality of the online classes on
[Coursera](http://coursera.org).

At present, I’m taking two classes, Machine Learning and Human-Computer Interaction.

[![small-icon.hover](/assets/images/legacy-blog/2012/05/small-icon.hover_-150x135.png.webp)](/assets/images/legacy-blog/2012/05/small-icon.hover_.png.webp)

The
[Machine Learning](https://www.coursera.org/course/ml) class is provided by Stanford University and
is taught by [Andrew Ng](http://ai.stanford.edu/~ang/).  The class is challenging but very
gratifying.  The class uses Octive/Matlab for its assignments.  The biggest challenge for me so far
has been the conversion of mathematical formulas into efficient “vectorized” Octave code.  I’ve
always taken for granted that matrix operations did specific tasks… like rotate a shape or change
the contrast in an image.  I’ve never really had to face the task of how they do it.  I enjoy that
the class takes you from zero knowledge of machine learning to a Neural Network that recognizes
handwriting in just the first 5 weeks.  Extremely gratifying.  As part of my learning process I’ll
be coding some of the stuff that I learned from the class in Java and later C++.  These things will
probably be useful as I work on the [pi](http://www.imdb.com/title/tt0138704/)-like stock market
predictor from my [previous post](/2012/05/22/another-pi-image-born/)…
Hopefully I won’t end up drilling a hole in my head.

[![small-icon.hover](/assets/images/legacy-blog/2012/05/small-icon.hover_1.png.webp)](/assets/images/legacy-blog/2012/05/small-icon.hover_1.png.webp)

the
Human-Computer interaction class only just started … so I have only gotten through the introduction
videos, but I can already tell that the class will affect and inform a lot of the design decisions
that I make in the future. The class is also provided by Sanford University and is taught by [Scott
Klemmer](http://hci.stanford.edu/srk/).   The class itself seems to be about formalizing the process
of making good user interfaces.  By formalizing, I don’t mean some kind of rigorous proof that X is
the best design, I just mean putting enough process around design that will make it approachable to
people who have no design intuition (like myself).  I have to wonder if maybe I can use this as an
excuse to explore some of [Buckmeister Fuller](http://en.wikipedia.org/wiki/Buckminster_Fuller)‘s
design and engineering principals…. I recently saw an exhibit at [SFMOMA](http://www.sfmoma.org/)
entitled “*The [Utopian Impulse: Buckminster Fuller and the Bay
Area](http://www.sfmoma.org/about/press/press_exhibitions/releases/903)“.*  Extremely inspiring.*
