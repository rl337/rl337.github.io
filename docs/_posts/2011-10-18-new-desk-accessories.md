This weekend I went through and added a couple new models to my desk
scene..[![mini-wireframe](/assets/images/legacy-blog/2011/10/mini-wireframe.png.webp)](/assets/images/legacy-blog/2011/10/mini-wireframe.png.webp)

First off, I wanted to model out a computer.  This is my rendition of a [mac
mini](http://www.apple.com/macmini/) (older model).  Right now it’s really just the basic shape and
a little bit of
[texturing](http://wiki.blender.org/index.php/Doc:Tutorials/Textures/Using_Textures)… but it’ll do.
The power light is always on, even if it’s not plugged in.  It occurred to me while I was modeling
this, I have no real idea how to make lights switch on/off… this is probably something I need to
look into.

[![lcd-wireframe](/assets/images/legacy-blog/2011/10/lcd-wireframe.png.webp)](/assets/images/legacy-blog/2011/10/lcd-wireframe.png.webp)

Along
with the computer, it seemed pretty obvious that I’d need a monitor of some kind.  This is a pretty
generic looking monitor.  I took the basic shape/button layout from a [Dell 17″
LCD](http://support.dell.com/support/edocs/monitors/1704fpt/en/about.htm) but stretched it out a
little to make it wide screen.  At the moment, the buttons are all blank, but at some point in the
future, I’ll add the [UV](http://en.wikibooks.org/wiki/Blender_3D:_Noob_to_Pro/UV_Map_Basics)
mapping for a power switch, +, -, and source.  The base isn’t very inspiring, but I didn’t really
want to spend a great deal of time on it…



Here’s a real rendering with the new computer components.  I still need to add cables, but in proper
lighting both of these models look pretty good… you should be able to click for the full sized
image.
