A while back, I picked up the book [Introducing Character Animation with
Blender](http://www.blender3d.org/e-shop/product_info_n.php?products_id=136) from
[blender3d.org](http://blender3d.org).  I primarily bought it to support the [blender
foundation](http://www.blender.org/blenderorg/blender-foundation/) because I love using the software
so much… but I finally got around to cracking it open.

[Original linked image: Introducing Character Animation in
Blender](http://www.blender3d.org/e-shop/images/640/char_anim.jpg)

Most of my blender knowledge comes from watching [youtube](http://youtube.com) videos.  This
approach is good because it provided me with a lot of practical modeling skills, but it doesn’t
delve much into the intention of the features built into blender.  I think that actually going
through and reading the manual will be useful for me at this point.

I think I’ll combine this getting back to basics with the actual character design of “[The
Weirdo](/2012/05/31/the-weirdo/)” for my video game project… kill two birds with one
stone so to speak.
