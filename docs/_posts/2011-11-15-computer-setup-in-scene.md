This
drawing represents how the main computer in the animation will be arranged.  It’s loosely based on
my actual computer layout.  Yes, voicing the Richard character from the
[script](https://docs.google.com/document/d/1lBsScHL7GYwovl2_ikfh0IJCZOexFMdok28WbuPMwDM/edit) isn’t
going to be a stretch for me!

In real life, my center display is an [iMac](http://www.apple.com/imac/) and I have a my
[Mini](http://www.apple.com/macmini/) set up to be a [shell
server](http://en.wikipedia.org/wiki/Bastion_host).  I don’t think that the Richard in the animation
would need a set up like this… instead he probably has a couple of home made
[linux](http://en.wikipedia.org/wiki/Linux) servers under his desk.

So, what needs to happen next… I have to model a set of
[headphones][archive-link-1],
customize the monitors so that three distinct monitor models exist.  I have to model a mouse and my
[Griffin
Powermate](http://www.amazon.com/Griffin-1100-PWRMTS-PowerMate-Multimedia-Controller/dp/B000RZO482)…
and I need to start working on the videos that will make up the monitor content.  The latter will be
the most challenging, I’m sure.  I honestly don’t know how [video as a
texture](http://wiki.blender.org/index.php/Doc:2.4/Manual/Textures/Types/Video) will render.
